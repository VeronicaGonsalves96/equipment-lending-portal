# equipment-lending-portal
School Equipment Lending Portal - Full Stack Web Application

## Quick start
1. Backend
	```bash
	cd backend
	npm install
	cp .env.example .env
	npm run dev
	```
2. Frontend
	```bash
	cd frontend
	npm install
	npm run dev
	```

See [SETUP_GUIDE.md](SETUP_GUIDE.md) for detailed setup and API summary.
